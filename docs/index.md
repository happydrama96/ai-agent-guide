# AI Agent 활용 가이드

> 공식 문서: [Claude Code](https://docs.anthropic.com/en/docs/claude-code/overview) · [Cursor](https://docs.cursor.com/) · [ChatGPT](https://learn.chatgpt.com/docs/quickstart) · [GitHub Copilot](https://docs.github.com/en/copilot)

## 이 사이트에서 찾을 수 있는 것

- 처음 고르는 사람을 위한 [에이전트 비교표](/getting-started/comparison)
- 결과를 눈으로 확인하는 [5분 첫 실행](/getting-started/first-run)
- 네 제품의 설치·인증·프로젝트 연결 가이드
- MCP와 사내 문서를 최소 권한으로 연결하는 방법
- 산문 대신 표로 찾는 명령어 치트시트
- 개발·기획·디자인·운영 직군별 실전 프롬프트

## 읽는 순서

처음이라면 **비교표 → 5분 첫 실행 → 선택한 에이전트 셋업**만 읽으면 됩니다. 이미 쓰고 있다면 검색창에서 오류 메시지나 명령어를 바로 찾으세요. 검색은 외부 서버로 보내지 않고 브라우저 안의 정적 인덱스에서 처리됩니다.

## 이 문서가 하지 않는 것

- 벤더 공식 문서 전체를 복제하지 않습니다.
- 화면 위치를 캡처 이미지로 고정하지 않습니다.
- 에이전트가 만든 결과를 검토 없이 배포하라고 권하지 않습니다.
- 로그인, DB, 백엔드 API, 방문자 분석을 사용하지 않습니다.
