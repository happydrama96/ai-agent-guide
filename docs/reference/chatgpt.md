# ChatGPT 치트시트

> 공식 문서: [명령 레퍼런스](https://learn.chatgpt.com/docs/reference/commands) · [프로젝트와 대화](https://learn.chatgpt.com/docs/projects) · [설정](https://learn.chatgpt.com/docs/reference/settings)

ChatGPT 웹·데스크톱은 계정과 점진 배포에 따라 보이는 기능이 다를 수 있습니다. 메뉴 이름이 달라지면 공식 문서에서 현재 경로를 확인하세요.

## 대화와 프로젝트

| 명령어 | 하는 일 | 언제 쓰나 |
| --- | --- | --- |
| `새 대화` | 빈 대화 시작 | 주제와 컨텍스트를 분리할 때 |
| `새 프로젝트` | 대화·파일·지침을 묶기 | 반복되거나 장기인 업무를 시작할 때 |
| `프로젝트 → 파일 추가` | 근거 자료 추가 | 프로젝트 대화에서 같은 자료를 재사용할 때 |
| `프로젝트 → 지침` | 프로젝트 전용 규칙 설정 | 출력 형식·용어·금지 사항을 고정할 때 |
| `대화 → … → 프로젝트로 이동` | 기존 대화를 프로젝트에 넣기 | 관련 작업을 한곳에 모을 때 |
| `대화 → 분기` | 특정 메시지에서 별도 흐름 시작 | 원본 대화를 보존하며 다른 안을 시험할 때 |

## 컨텍스트와 검증

| 명령어 | 하는 일 | 언제 쓰나 |
| --- | --- | --- |
| `첨부 → 파일` | 현재 대화에 파일 제공 | 일회성 분석에 쓸 때 |
| `도구 → 웹 검색` | 최신 웹 자료와 출처 검색 | 변할 수 있는 사실을 확인할 때 |
| `설정 → 개인화` | 전역 응답 선호 관리 | 모든 대화에 공통인 선호를 둘 때 |
| `설정 → 데이터 제어` | 데이터 관련 설정 확인 | 회사·개인 자료를 넣기 전 |
| `설정 → 연결/앱` | 외부 서비스 연결 관리 | 승인된 문서·업무 시스템을 연결할 때 |

## 데스크톱

| 명령어 | 하는 일 | 언제 쓰나 |
| --- | --- | --- |
| `Alt+Space` | Windows 빠른 대화 창 열기 | 다른 앱 위에서 바로 질문할 때 |
| `Option+Space` | macOS 빠른 대화 창 열기 | 다른 앱 위에서 바로 질문할 때 |
| `Ctrl+Shift+B` | Windows 내장 브라우저 열기 | 지원되는 Work·Codex 작업에서 웹을 함께 볼 때 |
| `Cmd+Shift+B` | macOS 내장 브라우저 열기 | 지원되는 Work·Codex 작업에서 웹을 함께 볼 때 |

## 안전 메모

전역 개인화에는 고객명·비밀값·프로젝트별 기밀 규칙을 넣지 않습니다. 외부 연결은 원본 서비스의 권한을 따르므로 공유 전 대상 워크스페이스와 문서 범위를 다시 확인하세요.
