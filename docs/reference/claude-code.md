# Claude Code 치트시트

> 공식 문서: [CLI 레퍼런스](https://code.claude.com/docs/en/cli-reference) · [명령어 레퍼런스](https://code.claude.com/docs/en/commands) · [대화형 모드](https://code.claude.com/docs/en/interactive-mode)

명령어는 계정, 요금제, 플랫폼에 따라 일부만 보일 수 있습니다. 세션에서 `/`를 입력하면 지금 쓸 수 있는 명령만 표시됩니다.

## 시작과 세션

| 명령어 | 하는 일 | 언제 쓰나 |
| --- | --- | --- |
| `claude` | 대화형 세션 시작 | 현재 프로젝트에서 작업할 때 |
| `claude "질문"` | 첫 요청과 함께 세션 시작 | 탐색 질문을 바로 보낼 때 |
| `claude -c` | 최근 대화 이어가기 | 직전 작업을 계속할 때 |
| `claude -r` | 세션을 골라 재개(ID·이름 지정 가능) | 예전 작업으로 돌아갈 때 |
| `/resume` | 세션 안에서 이전 대화 선택·재개 | 세션을 끄지 않고 다른 대화로 돌아갈 때 |
| `/clear` | 현재 대화 초기화 | 다른 주제로 완전히 바꿀 때 |
| `/compact` | 대화 내용을 요약해 컨텍스트 절약 | 긴 세션의 초점을 유지할 때 |
| `/context` | 컨텍스트 사용량을 격자로 표시 | 무엇이 컨텍스트를 차지하는지 볼 때 |
| `/exit` | 세션 종료 | 작업을 마칠 때 |

## 작업 흐름

| 명령어 | 하는 일 | 언제 쓰나 |
| --- | --- | --- |
| `/plan` | 계획 모드로 전환 | 큰 변경 전에 계획부터 합의할 때 |
| `/diff` | 작업 트리 변경과 Claude의 수정 확인 | 커밋 전에 변경을 검토할 때 |
| `/rewind` | 대화·코드를 이전 체크포인트로 되돌리기 | 수정 방향이 틀어졌을 때 |
| `/code-review` | 현재 diff나 PR 번호·브랜치의 버그 검토(`/review`는 별칭) | 커밋·PR 전에 자체 리뷰를 돌릴 때 |
| `/security-review` | 현재 브랜치 변경의 보안 취약점 분석 | 인증·입력 처리 코드를 바꾼 뒤 |
| `/tasks` | 현재 세션의 백그라운드 작업과 subagent 확인 | 병렬로 돌린 작업 상태를 볼 때 |

## 프로젝트와 상태

| 명령어 | 하는 일 | 언제 쓰나 |
| --- | --- | --- |
| `/init` | 프로젝트 지침 초안 생성 | `CLAUDE.md`를 처음 만들 때 |
| `/import` | Codex·Gemini CLI·Cursor 설정 가져오기 | 다른 코딩 에이전트에서 옮겨 올 때 |
| `/memory` | `CLAUDE.md` 편집, 자동 메모리 확인·끄기 | 규칙 적용 상태를 볼 때 |
| `/status` | 버전·모델·계정·연결 상태 확인 | 인증과 실행 환경을 점검할 때 |
| `/config` | 설정 화면 열기 | 테마, 모델, 지침 파일 로딩 방식을 바꿀 때 |
| `/permissions` | 도구 권한 확인·조정 | 반복 승인이나 차단 원인을 볼 때 |
| `/mcp` | MCP 서버 상태와 인증 관리 | 외부 도구 연결을 점검할 때 |
| `/plugin` | 플러그인 검색·설치·활성화 관리 | 플러그인을 추가하거나 상태를 볼 때 |
| `/skills` | 사용 가능한 Skills 목록 확인 | Skill이 로드됐는지 볼 때 |
| `/hooks` | 설정된 hooks를 이벤트별로 확인 | 자동 동작의 출처를 찾을 때 |
| `/doctor` | 설치·설정·확장·`CLAUDE.md` 점검 후 수정 제안(확인 후 적용) | 세션 안에서 환경 문제를 확인할 때 |
| `/doctor prompt-audit` | `CLAUDE.md`, Skills, agents, 명령의 오래된 프롬프트 패턴 점검 | 모델을 바꾼 뒤 지침을 정리할 때 |

## 비대화형 실행

| 명령어 | 하는 일 | 언제 쓰나 |
| --- | --- | --- |
| `claude -p "질문"` | 답을 출력하고 종료 | 파이프라인·간단 조회에 쓸 때 |
| `claude -p --output-format json "질문"` | JSON 결과 출력 | 후속 스크립트가 파싱할 때 |
| `claude -p --max-turns 3 "질문"` | 에이전트 턴 수 제한 | 자동화 비용과 범위를 제한할 때 |
| `claude --model sonnet` | 세션 모델 지정 | 속도·성능 선택을 명시할 때 |
| `claude --add-dir ../shared` | 추가 폴더 접근 허용 | 모노레포 밖 공용 코드를 읽힐 때 |
| `claude plugin install <플러그인>@<마켓플레이스>` | 세션 없이 셸에서 플러그인 설치(기본 사용자 범위) | 설치 스크립트로 팀 환경을 맞출 때 |

## 백그라운드 세션

| 명령어 | 하는 일 | 언제 쓰나 |
| --- | --- | --- |
| `/background` | 현재 세션을 백그라운드로 분리하고 터미널 비우기 | 긴 작업을 계속 돌려 두고 다른 일을 할 때 |
| `claude agents` | 백그라운드 세션 목록과 상태 보기 | 병렬로 돌린 세션을 관리할 때 |
| `claude attach <ID 또는 이름>` | 백그라운드 세션에 다시 연결 | 진행 중인 세션을 이어서 볼 때 |

## 유지관리

| 명령어 | 하는 일 | 언제 쓰나 |
| --- | --- | --- |
| `claude --version` | 설치 버전 출력 | 문제 재현과 업데이트 확인 |
| `claude doctor` | 세션 없이 설치·설정 파일 상태 진단 | 실행 파일이 꼬였을 때 |
| `claude update` | 수동 업데이트 | 자동 업데이트를 기다리지 않을 때 |
| `claude auth status --text` | 로그인 상태 확인 | 인증 문제를 셸에서 확인할 때 |
| `/usage` | 세션 비용과 사용량 표시(`/cost`는 별칭) | 긴 작업의 사용량을 점검할 때 |

## 안전 메모

`--dangerously-skip-permissions`는 승인 경계를 없애므로 이 가이드에서는 사용 예를 제공하지 않습니다. 자동화는 허용 도구, 최대 턴, 작업 디렉터리를 각각 좁히고 사람이 diff를 승인하는 단계와 분리하세요.
