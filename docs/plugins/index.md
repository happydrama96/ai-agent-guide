# 플러그인 고르는 기준

> 공식 문서: [Claude Code 플러그인](https://code.claude.com/docs/en/plugins) · [Cursor 플러그인](https://cursor.com/docs/plugins) · [ChatGPT 플러그인](https://learn.chatgpt.com/docs/plugins) · [GitHub Copilot 플러그인](https://docs.github.com/en/copilot/concepts/agents/about-plugins)

플러그인은 기능 수보다 **설치 뒤 생기는 권한과 운영 부담**을 먼저 봅니다. 기본 기능으로 해결되지 않는 반복 문제를 분명히 줄일 때만 추가합니다.

## 권한 범위

설치 화면의 설명만 보지 말고 저장소의 manifest, Skills, hooks, 실행 스크립트를 함께 확인합니다. 다음 중 하나라도 포함되면 쓰기 권한이 필요한 이유와 중단 방법이 문서화되어 있어야 합니다.

- 프로젝트 밖 파일 읽기·쓰기
- 셸 명령과 패키지 설치
- Git 커밋·푸시·PR 생성
- 브라우저 입력·제출
- 외부 서비스의 생성·수정·삭제 작업
- 세션 종료 전후에 자동 실행되는 hook

처음에는 사용자 전체가 아니라 프로젝트 범위, 전체 허용이 아니라 요청 시 승인으로 설치합니다.

## 유지보수 상태

활성도는 인기도가 아니라 공식 저장소의 마지막 릴리스 또는 커밋으로 판정합니다.

| 활성도 | 판정 기준 | 문서 처리 |
| --- | --- | --- |
| 활발 | 최근 3개월 내 릴리스 또는 커밋 | 설치법과 권한을 확인하고 추천 가능 |
| 유지보수만 | 3~12개월 내 활동, 버그 수정 위주 | 새 프로젝트 도입은 대체재와 함께 검토 |
| 정체 | 12개월 이상 활동 없음 | 기본 추천에서 제외하고 기존 사용자 참고용으로만 유지 |
| 중단 | 저장소 아카이브 또는 공식 중단 공지 | 경고 박스와 확인된 대안을 표시 |

마지막 활동일은 저장소 전체가 아니라 해당 플러그인 디렉터리나 패키지를 기준으로 확인합니다.

## 사내 데이터 외부 전송 여부

플러그인이라는 이름만으로 로컬 실행을 보장하지 않습니다. Skill만 제공해도 에이전트가 외부 CLI나 클라우드 작업자를 호출할 수 있고, connector를 포함하면 연결된 서비스로 질의와 파일이 전달될 수 있습니다.

설치 전에 다음 경계를 적을 수 있어야 합니다.

1. 어떤 파일과 대화 내용을 읽는가
2. 어느 회사의 서버로 무엇을 보내는가
3. 외부 시스템에서 어떤 변경을 만드는가
4. 인증 토큰이 어디에 저장되고 어떤 프로세스가 상속하는가

이 네 항목 중 하나라도 공식 자료로 확인되지 않으면 사내 데이터 작업에는 사용하지 않습니다.

## 대체 가능성

에이전트 기본 기능, 저장소 지침 파일, 기존 테스트 명령으로 같은 문제를 해결할 수 있으면 플러그인을 추가하지 않습니다. 비슷한 플러그인을 겹쳐 설치하면 명령 충돌, 중복 hook, 상반된 지침이 생길 수 있으므로 한 문제에는 기본 도구 하나만 둡니다.

도입 전에 제거했을 때 잃는 기능을 한 문장으로 설명할 수 있어야 합니다. 설명이 “더 똑똑해진다” 수준이면 도입 근거가 부족합니다.

## 설치 난이도

설치 명령 하나만 보지 않고 인증, 런타임, 네트워크, 제거까지 포함해 판정합니다.

| 난이도 | 기준 |
| --- | --- |
| 쉬움 | 마켓플레이스 설치만 필요하고 추가 인증·런타임이 없음 |
| 보통 | 외부 계정 인증, API 키, CLI 또는 별도 런타임 중 하나가 필요 |
| 어려움 | 사내 네트워크 예외, 복수 서비스 권한, 서버 운영 또는 배포가 필요 |

제거 명령이나 비활성화 경로가 공식 문서에 없으면 설치 난이도를 한 단계 높여 봅니다.

## 이 섹션 점검 방법

1. 분기 1회, 각 요약표의 `최종 확인`이 오래된 항목부터 공식 문서와 저장소를 엽니다.
2. 해당 플러그인의 마지막 활동일을 확인하고 위 기준대로 활성도 등급만 먼저 갱신합니다.
3. 설치 명령·권한·데이터 전송 범위가 바뀐 항목만 본문과 최종 확인일을 함께 수정합니다.
4. 중단 항목은 삭제하지 않고 경고와 확인된 대안을 남기며, 공식 출처가 사라진 후보는 새 추천에서 제외합니다.
